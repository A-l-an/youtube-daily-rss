# 私密持仓指导 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for your owned task and test cycle. The parent delegates the tightly coupled source/evidence/report implementation as one feature, owns real-data acceptance, and requests a fresh whole-feature review; no nested delegation.

**Goal:** 从两个券商的现有私密账本与当日/近七天频道证据，生成可追溯的 DeepSeek Pro 持仓指导。

**Architecture:** 原公开日报只读复用；私密源适配器先投影允许字段，再交给独立分析与文件输出流程。配置/报告/缓存全部在仓库之外。沿用 Python、标准库、现有 OpenAI client 与字幕抓取器，不增依赖或服务。

**Spec:** `docs/持仓指导_方案_26-10-23.md`

## Global Constraints

固定 `deepseek-v4-pro`；两个券商均应读取；没有账户号码/ID、股数、资产金额、备注或凭据出站/落报告/进日志/Git；只读 Portfolio Local；报告按 Asia/Shanghai 日期；7日窗口；保留未知与不足；无自动交易；代码不推送直至用户新授权。

## Review Focus

- 缺报价被置零：不能解释成空仓或确定零权重。
- 行情日期与稀疏快照：不能声称今日券商持仓已核对。
- 已保存失败日报、跨日期重复视频：不能充当一周的独立证据。
- 环境 SUMMARY_MODEL=flash：个性化调用仍必须为 Pro；异常和截断不能保存成成功。
- 输出配置/软链/文件碰撞：禁止写入 repo/public，禁止覆盖已有用户内容或泄露私密输入。

### Task 1: 私密持仓源

Files: `scripts/portfolio_source.py`, `tests/test_portfolio_source.py`.

Interface: `fetch_portfolio(source_config: dict, as_of: date) -> dict`; `PortfolioSourceError` exposes only fixed safe codes. source_config keys `base_url`, optional `connect_address` (IP-only, TLS hostname verified), `password_file`, `account_aliases` mapping exact account names to `{alias, broker}` (broker is futu or hsbc; private config only).

Output: schema_version=1, fetched_at, as_of_date, brokers, accounts (alias, broker, currency, positions_as_of, positions_source, broker_verified=false), positions. Each position: key, account_alias, broker, symbol, currency, direction, recorded_account_weight_pct, portfolio_security_weight_pct, cost_to_price_deviation_pct, cost_status, positions_as_of, positions_source, quote_as_of, quote_is_stale, valuation_available. No other raw financial/account fields.

- [x] Implement bounded HTTPS login/profile/accounts/holdings-list/snapshots/quotes-latest; cookie/scope only in memory. No ledger mutation or quote refresh.

### Task 2: 证据、Pro 与私密报告

Files: `scripts/portfolio_evidence.py`, `scripts/portfolio_guidance.py`, `tests/test_portfolio_evidence.py`, `tests/test_portfolio_guidance.py`.

Interfaces: `build_evidence(summaries: dict, as_of: date, cache_dir: Path, transcript_config: dict, recover_captions: bool=True) -> dict`; `run(config_path: Path, as_of: date|None=None, force: bool=False) -> dict` with safe status metadata only. Guidance imports `fetch_portfolio` from Task1.

Private config root keys: `enabled`, `source` (Task1 schema), `output_dir`, optional `cache_dir` outside repo, `holdings_confirmed_at` fixed at the actual human-confirmation date (never automatically rolled forward). Model is fixed in code; not overridden by SUMMARY_MODEL. A CLI `--config` (default ~/.config/youtube-daily-rss/portfolio-guidance.json), `--date`, `--force`, `--check-only` supports validation without model call. Missing/disabled config returns skipped; invalid config fails explicitly.

Evidence: actual source IDs/URLs/date/kind and source-limited content; successful public summaries + recovered captions from unsuccessful daily entries only, video dedup and 7-day boundary. No historical ASR. Store captions privately, bounded no repeated fetch on normal same-day replay. Canonical evidence payload reports covered dates/missing dates/source gaps; unavailable sources cannot become evidence. Latest-day and insufficient-week states rendered explicitly.

Model call: existing credentials/client, official endpoint, exactly deepseek-v4-pro, high thinking, strict JSON, max_tokens32768, bounded timeout/no automatic model fallback, reject finish_reason length/empty/schema errors/unprovided evidence IDs. Do not persist reasoning. One output per holding key with coverage/status/conditional_action/conditions/risks/evidence_ids, plus portfolio overview and week overview. User-readable output has source links generated from known evidence; numbers/weights rendered from local validated input.

- [x] Test date boundary, duplicate sources, failed/partial days, caption cache, no ASR, no false whole-week coverage.
- [x] Test model/body exact Pro despite SUMMARY_MODEL, projection, empty/length/invalid-reference responses, no private exception output.
- [x] Implement private mode600 files/dir700, hash-based idempotency excluding fetched_at, explicit revision on changed inputs, reject repo-contained/symlink output. Never write public files or user meaning-layer notes.
- [x] Test private-only output/revisions/collisions and public tree unchanged with synthetic holdings.
