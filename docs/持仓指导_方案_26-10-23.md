# 私密持仓指导方案

功能范围：按本机配置选择富途和汇丰账户，将股票代码、仓位比例、成本相对现价偏离交给 DeepSeek Pro，生成私密的当日与近七天观点、条件式持有/减仓/观察说明。实际账户映射、个人确认记录及运行结果仅存本机，不进入本仓库。

## 最小实现

- 原公开日报继续使用既有流程。增加独立私密报告 CLI，读取现有 `summaries.json`；输出根目录必须在 Git 仓库之外，默认 Finance Vault 的“持仓指导”。
- 只读访问现有 Portfolio Local HTTPS API。登录 cookie 与 profile scope 只在内存；复用两个券商下的全部已识别非归档账户。账户号码/ID、股数、资产金额、自由备注、密码不进入模型、日志、报告或 Git。
- `deepseek-v4-pro` 固定，无 Flash 回退；思考模式 high，单次生成，复用既有官方 API 凭据。公开摘要仍为原模型。
- 分开标注本地持仓快照、行情日期、读取时间。Portfolio Local 未建立券商实时同步；不把行情更新当作持仓核对。另列本机配置的实际人工确认日期，后续日期不自动延长该确认。未知/过期行情、未知成本及零成本保留原状态。
- 最新日有结构化直接摘要时，逐频道展示已有原观点；模型负责周对照、个人影响及条件分析。没有对应摘要时明确标注模型整理和资料缺口。
- 每只证券给出：最新一日相关观点、近七天变化与分歧、对该持仓的影响、条件式操作思路、失效条件、来源。模型只能引用实际提供的证据 ID；未覆盖标的显示间接影响或信息不足。投资期限与风险预算未知，不生成精确下单数量或收益保证。
- 权重注明“账本所记录的权重”；跨账户证券权重在同一基础币种、估值完整时计算，缺报价时保留未知。成本偏离为 `(成本/证券市值 - 1) × 100%`，不是历史收益率。
- 周窗口为上海日期当天及前六天；同一视频只计算一次。失败日报不作证据。对失败日报里曾成功取得字幕的旧视频，复用字幕抓取器补取文本并私密缓存；不为历史周窗口自动排队大量 ASR。覆盖不足时直接标出日期与缺失来源，不能声称完整周趋势。
- 文件名 `持仓指导_日报_YY-MM-DD.md`，重复相同输入复用结果；变化时用 `_vN` 修订。缓存/报告权限 600，目录700；不覆盖用户文件。

## 接入与验收

复用现有 self-hosted daily workflow；私密步骤放在公开提交/Pages 发布之后，且以显式开关启用。配置和输出均只存本机。实现后先进行真实只读双账户读取、Pro 生成和本地报告验收，再申请新功能的推送/定时启用授权（旧授权仅覆盖 ASR 修复）。

验证：私密字段白名单、两个券商覆盖、错误/未知数据处理、7天边界与视频去重、旧字幕恢复、只使用 Pro、引用校验、私密目录隔离/无覆盖/幂等、公开输出不变，以及独立审查。真实持仓无需写入测试夹具。

官方模型依据：https://api-docs.deepseek.com/quick_start/pricing/ ，2026-10-23核对模型名 deepseek-v4-pro，并完成39 tokens的不含持仓真实调用。
